# 케이스 스터디 — Vibe vs Spec: 같은 페이지, 다른 과정

대화형 웹 빌더 에이전트로 **동일한 카페 랜딩 페이지**를 두 가지 방식으로 생성하고
토큰·비용을 비교한 실전 기록. 측정일 2026-08-15.

이 케이스는 저장소의 두 주장과 직접 맞물린다:

- **exp04 (SDD)** — "스펙 먼저"가 비용을 줄이는가 → 이 케이스는 단일 턴 안에서도
  스펙이 추론·출력 토큰을 줄이는 것을 보여준다.
- **README 반증 절** — "Spec-Kit은 토큰 +97~109%"의 반례. **짧고 결정만 담은
  4필드 스펙**은 토큰을 거의 늘리지 않았다(+1.8%). 결론("짧은 스펙을 써라")을
  지지하는 데이터 포인트.

## ⚠️ 측정 방식 (정직성 고지)

이 저장소의 exp08과 달리 **실제 API 청구서가 아니다.** 에이전트 세션의 토큰
사용량 추정치이며, 절대값보다 **모드 간 상대 비교**로 읽어야 한다.
단가는 GPT-5 공개 리스트($1.25 / $10 / $10 / $0.125 per 1M; 추론은 출력 요율)를 적용했다.

## 실험 설계

| | ✨ Vibe | 📐 Spec |
|---|---|---|
| 입력 | 자연어 한 문장 (25자) | 4필드 결정적 스펙 (pages·stack·design·ac) |
| 설계 판단 | 전부 에이전트 재량 | 스펙으로 선결정, 에이전트는 구현만 |
| 검증 | 없음 | AC 자동 검증 16항목 게이트 |
| 산출물 | `artifacts/index_vibe.html` | `artifacts/index_spec.html` |

Spec의 스펙은 Vibe 산출물을 **역산**해 작성했다 (동일 산출물 조건 통제).
전체 요청/응답 원문은 `transcripts/`에 있다.

## 결과

### 토큰 (usage.json)

| 구분 | Vibe | Spec | 차이 |
|---|---:|---:|---:|
| 입력 | 486 | 1,152 | **+137%** (스펙 텍스트만큼) |
| 추론 | 1,240 | 980 | **−21%** ("무엇을 만들지" 선결정) |
| 출력 | 5,830 | 5,410 | **−7%** (스펙 외 요소 미생성) |
| 캐시 | 312 | 468 | +50% |
| **합계** | **7,868** | **8,010** | **+1.8%** |

### 비용 (GPT-5 단가)

| | Vibe | Spec | 차이 |
|---|---:|---:|---:|
| 합계 | $0.07135 | $0.06540 | **−8.3%** |

토큰은 더 썼는데 돈은 덜 들었다. 늘어난 것은 싼 토큰(입력 $1.25/M),
줄어든 것은 비싼 토큰(추론·출력 $10/M). 입력:출력 단가비 1:8이 지렛대다.

### 단가비 민감도 (실험 E — `sensitivity.py`)

이 -8.3%가 GPT-5 단가에 특수한 결과인지 검증했다.

- 손익분기 단가비 r* = **1.0024** — 출력 단가가 입력보다 0.24%만 높아도 Spec 승리.
  알려진 모든 상용 모델은 r ≥ 3.7 이므로 이 토큰 이동은 **단가 체계와 무관하게 흑자**.
- 단, 절감률의 상한은 **-9.6%** (출력 감소분 -680/7,070의 극한).
  실측: GPT-5·Gemini -8.3%, Claude 계열 -7.6%, DeepSeek -7.1%.
- **결론: 1턴 효율의 이득은 한 자릿수가 상한이다. 더 큰 절감은 재작업 턴 수
  감소에서 나와야 하며, 그것은 아직 미실증이다 → `EXPERIMENT_A_PROTOCOL.md`**

### 산출물 차이

첫 화면은 육안으로 거의 구분 불가 (`shots/` 스크린샷 참고).
차이는 디테일: Vibe는 재량 요소(eyebrow 배지·도로명 라벨·팔레트 밖 색)를
생성했고, Spec은 스펙 외 요소를 만들지 않는 대신 CSS 변수 토큰화·시맨틱
마크업·aria-label을 준수했다. AC 검증은 16/16 통과.

## 한계와 다음 단계

- 표본 1쌍. 통계적 주장이 아니라 케이스 스터디다.
- 토큰 수치는 추정치 (위 고지 참고). 품질(디자인 선호도 등)은 측정하지 않았다.
- Spec의 스펙이 Vibe 산출물의 역산이므로, "백지에서 스펙 작성" 비용은 포함되지 않았다.
- **1턴 비교라서 SDD의 핵심 주장(재작업 감소)을 검증하지 못한다.** 절감 상한도
  -9.6%로 좁다 (`sensitivity.py`). 재작업 실험의 사전등록 설계는
  `EXPERIMENT_A_PROTOCOL.md` 참고 — 요구 변경 3종(디자인·구조·모순)을 두 경로에
  투입해 누적 비용 곡선(N² 가설)과 회귀 횟수를 실측할 계획이다.
- "빠르다"(시간)는 아직 어떤 데이터로도 뒷받침되지 않는다. 실험 A의 wall_clock이
  최초 근거가 될 것이다.
