# 발표자 빠른 시작

현행판은 **2026-09-20 정정판**입니다. [덱·PDF·대본 목록](README.md)을 사용하세요.

1. PDF를 기본 백업으로 준비합니다. PPTX는 NanumGothic 폰트를 사용합니다.
2. 수치만 말하지 말고 각 슬라이드 상단의 **증거 범위**와 하단의 출처도 확인합니다.
3. 240배는 기존 환산/자동 대 미지정이며, 정확도 동등성의 증거가 아닙니다.
4. `archive/`의 옛 대본·검증 PASS 수·단가를 현행 자료와 혼용하지 마세요.
5. 라이브 API 시연은 키·권한·지원 파라미터·과금이 필요하며, 저장 로그의 숫자가 다시 나온다는 보장이 없습니다.

최종 확인:

```bash
python tools/verify_deck.py --with-pdf
```

검증기는 수치·문구·파일 정합을 봅니다. 발표장 기기의 폰트·화면·USB 열림은 별도 현장 확인입니다.
