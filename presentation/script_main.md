## 5. 짧은 한국어가 적은 의미를 뜻하지 않는다

## 8. 간단한 계산에도 사고가 비용을 크게 늘린다

**약 199.47배 / 기존 240.02배** · 저장 로그 + 두 단가의 재계산

- 자동(-1) / 미지정 비교. 같은 문제를 조건당 6번 실행한 저장 로그.
- ±$0.05 허용오차 통과는 각각 6/6. 일반 정확도의 동등성 증명은 아니다.
- 자동 / 명시적 0은 Standard 195.97배. 명시적 0은 5/6.
- 240배 메시지는 기존 환산 단가라는 조건을 붙여 유지한다.

근거: `results/thinking_sweep.jsonl (30 rows) · tools/thinking_sweep.py`

## 9. 미지정과 0을 합치지 않는다

**6/6 · 5/6 · 2/6 · 6/6 · 6/6** · 채점 기준·표본 한계 공개

- 순서: 미지정 / 명시적 0 / 512 / 2048 / 자동(-1), ±$0.05 기준

- 512 조건은 모두 STOP, 사고 127–154 토큰. ‘예산에 잘려 오답’이라는 원인은 미확인.

## 10. Welch 검정은 t분포를 쓴다

**t = 6.188 · 자유도 = 35.713** · 통계 구현 교정

- reason / 문자당 / 기존 단가: 정규근사 6.08e-10 → Welch 4.02e-07
- 평균 차이의 표준오차를 표본에서 추정하므로 정규분포보다 꼬리가 두꺼운 t분포를 사용.
- p = 2 × t.sf(|t|, df). 1-CDF는 작은 꼬리에서 정밀도를 잃을 수 있다.
- p값은 수정해야 한다. 유의성의 소멸을 뜻하지는 않는다.

근거: `tools/stats_test.py · scipy.stats.ttest_ind(equal_var=False) 회귀 대조`

## 13. DRY: 전체 파일 대신 변경분을 받는다

## 14. 압축과 캐싱은 대체재만이 아니다
