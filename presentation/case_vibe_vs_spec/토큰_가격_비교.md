# 💰 토큰 가격 비교 — Vibe vs Spec (카페 온도 랜딩)

두 실행의 사용량에 대표 모델 2종의 공시 단가를 적용한 비용 비교.
환율 기준: **1 USD ≈ ₩1,390** (2026-08 근사치)

## 0. 적용 단가 (per 1M tokens)

| 구분 | Claude Sonnet 4.5 | GPT-5 | 비고 |
|---|---:|---:|---|
| 입력 (Input) | $3.00 | $1.25 | |
| 추론 (Reasoning) | $15.00 | $10.00 | **양사 모두 출력 단가로 과금** |
| 출력 (Output) | $15.00 | $10.00 | |
| 캐시 읽기 (Cache read) | $0.30 (입력의 1/10) | $0.125 (입력의 1/10) | 캐시 히트 시 90% 할인 |

> ⚠️ 추론(reasoning/thinking) 토큰은 별도 단가가 없고 **출력 토큰과 동일 요율로 청구**됩니다.
> 캐시는 "읽기" 기준. (Claude는 캐시 쓰기 시 $3.75/M가 별도지만 여기선 읽기만 적용)

## 4. 비용 구성비 (Claude 기준, Vibe)

```
출력   ████████████████████████████████░  81.3%
추론   ██████░                            17.3%
입력   ▌                                   1.4%
캐시   ·                                   0.1%
```

## 5. 핵심 인사이트

1. **토큰 수는 Spec이 +1.8% 더 썼지만, 비용은 오히려 −7.6~−8.5% 저렴.**
   - 이유: 늘어난 건 **싼 토큰**(입력 $3, 캐시 $0.30), 줄어든 건 **비싼 토큰**(추론·출력 $15).
   - 입력:출력 단가비가 1:5라서, 스펙으로 추론 260 + 출력 420 토큰을 줄인 효과가
     입력 666 토큰 증가분을 상쇄하고도 남음.
2. **비용의 98%+가 추론+출력에서 발생** → 프롬프트를 아끼는 것보다 *출력을 정확히
   한 번에 뽑는 것*이 비용 최적화의 핵심. 재생성 1회가 스펙 작성 10회보다 비쌈.
3. **캐시 비용은 사실상 0** (전체의 0.1%) → 반복 세션에서 시스템 프롬프트·스펙을
   캐시에 태우면 입력 비용의 90%를 절감하므로 적극 활용 대상.
4. 모델 선택: 동일 작업 기준 GPT-5가 Claude Sonnet 대비 **약 34% 저렴**
   (단, 실제 토크나이저·추론량 차이로 사용량 자체가 달라질 수 있음 — 여기선 동일 사용량 가정).

## 6. 결론

> **"결정적 스펙은 공짜가 아니라 흑자다."**
> 스펙 작성으로 입력이 2.4배 늘어도, 비싼 추론·출력이 줄어 건당 비용은 ~8% 절감.
> 여기에 재현성·검증 가능성(AC 16/16)까지 얻으므로, 반복 작업일수록 Spec 모드가 유리.
