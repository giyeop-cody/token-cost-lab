## 1. 토큰 사용량 비교

| 구분 | 입력 | 추론 | 출력 | 캐시 | **합계** |
|---|---:|---:|---:|---:|---:|
| ✨ Vibe | 486 | 1,240 | 5,830 | 312 | **7,868** |
| 📐 Spec | 1,152 | 980 | 5,410 | 468 | **8,010** |
| 차이 (Spec−Vibe) | **+666** | **−260** | **−420** | **+156** | **+142 (+1.8%)** |

### 해석
- **입력 +137%**: Spec 모드는 페이지 구성·스택·디자인 토큰·AC 5항목이 프롬프트에 포함되어 입력 토큰이 크게 증가.
- **추론 −21%**: "무엇을 만들지" 고민이 스펙으로 이미 결정되어 있어 추론 비용 감소. *(스펙이 추론을 대신한다)*
- **출력 −7%**: 스펙 외 요소를 만들지 않으므로 출력이 줄어듦 (아래 산출물 diff 참고).
- **캐시 +50%**: 직전 세션의 팔레트·구조가 컨텍스트로 재사용됨.
- **총합은 +1.8%로 비슷**하나, 비용 구조가 "추론↓ 입력↑"으로 이동 → **결과 예측 가능성을 토큰 142개로 구매한 셈.**

### 내용 차이 (diff 요약)

**Vibe에만 있는 것** (스펙에 없어서 Spec에서 제거됨):
- 히어로 eyebrow 배지 "수원 행궁동 · 매일 로스팅"
- 히어로 장식 원 2개 (green/caramel 도트)
- 지도 도로명 라벨 ("행궁로", "정조로")
- 영업시간 L.O(라스트오더) 표기
- 지도 핀 색상 빨강(#c0392b)

**Spec에만 있는 것**:
- `--r-card/--r-btn/--sec-pad` 디자인 토큰 변수화
- `overflow-x:hidden` (AC3 가로 스크롤 차단 명시 대응)
- `<article>`, `<ul>` 시맨틱 마크업, SVG `aria-label`
- 지도 핀 색상 팔레트 준수(caramel #c08552)
