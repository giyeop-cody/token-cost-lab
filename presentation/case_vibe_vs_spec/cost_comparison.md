# 가격 비교 — 고정된 usage 추정치의 환산

GPT-5 $1.25/$10, 캐시 $0.125/M 가정: Vibe $0.0713465, Spec $0.0653985 (약 -8.3%).
Sonnet $3/$15, 캐시 $0.3/M 가정: Vibe $0.1076016, Spec $0.0994464 (약 -7.6%).
**모델 간 실제 호출이 아니다.** usage 추정값을 고정한 민감도 계산이며 환율도 실측 절감 효과가 아니다.

최신 재계산은 `demo/vibe_vs_spec/sensitivity_results.json`과 `lab/pricing.py`를 참고한다.

캐시 할인 적격성은 미확인이다. GPT-5에서 전부 신규 입력으로 환산하면 $0.0716975 → $0.0659250 (약 -8.1%).
