# 사라진 주장 정리 — 어디로 갔고, 다시 말할 수 있는가

기준 **`ef4cde1`**(2026-09-13) → 현행 **`44a208a`**(2026-09-20 정정판) · 새 유료 API 호출 **0회**.

정정 과정에서 **문구가 사라진 주장**을 모은 문서다. [CORRECTIONS.md](CORRECTIONS.md)가 “무엇이 틀렸고
무엇을 고쳤는가”, [REASSERTED.md](REASSERTED.md)가 “그래서 무엇을 다시 말할 수 있는가”라면,
이 문서는 **“무엇이 사라졌고, 왜 사라졌으며, 되살릴 조건은 무엇인가”**다.

지운 문장은 없어지지 않았다. 원문은 git 기록 `ef4cde1`과 `docs/archive/`, `presentation/archive/`에 있다.
현행 문서에서 빠졌다는 것은 **주장으로 쓰지 않기로 했다**는 뜻이다.

분류:

- **A. 값이 틀려 대체된 것** — 다시 말할 수 있다(대체 문구로).
- **B. 원자료가 없어 격리한 것** — 재주장 금지(새로 측정하지 않는 한).
- **C. 측정한 적이 없어 삭제한 것** — 측정 전 재주장 금지.
- **D. 값은 살아 있고 문서 문구만 빠진 것** — 스크립트 출력을 인용해 다시 말할 수 있다.
- **E. 표기 자체를 금지한 것** — 회귀 테스트로 재등장을 막는다.

## E. 금지 표기 (회귀 테스트로 재등장 차단)

아래 표기는 **현행 주장 표면**(`presentation/` 비아카이브, `README*`, `SOURCES.md`, `LIVE_RESULTS.md`,
`demo/`, `agent_setup/`, `experiments/`)에 다시 나타나면 테스트가 실패한다는 규칙으로 관리한다.
값을 되살리려면 §A의 대체 문구를 쓰거나, 새 측정을 근거로 이 문서를 고친다.


이 목록은 “과거가 틀렸다”는 목록이 아니라 **“근거 없이 다시 쓰지 않기로 한 표기”** 목록이다.
대응하는 옛 문장과 사유는 §A~§C에 있다.

**§E에서 뺀 표기 — `30분`.** 발표 자료가 30분 분량이라는 주장은 장수·내용과 맞지 않아 금지했었다.
2026-09-21 발표체 재작성으로 덱 5종을 모두 **약 30분 분량**(장당 멘트가 담긴 발표자 노트 포함)으로
다시 만들었으므로, `10분/20분/30분` 같은 시간 표기는 **“목표 분량”**으로만 쓰고 실제 발표 시간 측정값으로는
쓰지 않는다. 표기는 `presentation/README.md`와 대본 머리에 있다.
